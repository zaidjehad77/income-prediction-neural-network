# Income Prediction: Neural Network vs Decision Tree

Neural Networks & Deep Learning project comparing an Artificial Neural Network (Keras) with a Decision Tree classifier on the UCI Adult Income dataset.

## Tech Stack
Python · TensorFlow / Keras · Scikit-learn · Pandas · NumPy

## Highlights
- Data preprocessing: missing values, duplicates, encoding, and scaling.
- Built and trained a fully connected ANN with Keras (Sequential / Dense).
- Trained a Decision Tree baseline for comparison.
- Compared performance using accuracy and confusion matrices.

## Repository Contents
- `Copy_of_Income_Predication.ipynb`: full notebook
- `Model.docx`: model report
- `adult.csv`: dataset
